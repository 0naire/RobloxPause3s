# 검증 기록

## 2026-10-28 배포 준비 빌드

- 환경: Windows 11 x64, .NET Framework C# 컴파일러, 관리자 권한
- 실행 파일: 현재 저장소의 `source/`를 빌드한 `dist/RobloxPause3s.exe`
- 대상: `tests/bin/RobloxPlayerBeta.exe`라는 이름의 **전용 테스트 프로그램**
- 통신 범위: `127.0.0.1`, `::1`의 로컬 TCP/UDP
- 실제 Roblox 게임이나 외부 서버 연결은 테스트 대상으로 사용하지 않음

| 항목 | 결과 |
| --- | --- |
| 차단 전 TCP/UDP, IPv4/IPv6 연결 | 통과 |
| 실제 작업 프로세스를 통한 대상 경로 차단 | 통과 |

| 차단 중 다른 실행 파일의 연결 유지 | 통과 |

| 작업 프로세스 강제 종료 후 동적 필터 제거 | 통과 |

전체 결과는 [test-results.txt](test-results.txt)에 있습니다. 재현 방법은 저장소 루트에서 관리자 권한으로 `tests/run.ps1`을 실행하는 것입니다. 테스트용 실행 파일과 통신 로그는 `tests/bin/`에 생성되며 Git에서 제외됩니다.

이 검증은 로컬 차단 및 해제 동작을 확인한 것입니다. Roblox의 모든 경험에서 세션이 유지되는지, 게임 내 시간이 멈추는지, 서버가 특정 방식으로 반응하는지는 확인하거나 보장하지 않습니다.

이전 빌드에서 발견한 카운트다운 표시 영역 겹침 수정과 준비 중 취소 요청 처리 수정이 이번 소스 및 배포 파일에 포함되어 있습니다. 시각적 UI 검사는 이번 통합 테스트의 범위에 포함하지 않았습니다.
