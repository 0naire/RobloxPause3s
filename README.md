# RobloxPause3s

**단축키 한 번으로 Roblox의 네트워크 연결을 약 3초간 차단하고, 시간이 지나면 차단을 자동 해제하는 Windows 프로그램입니다.**

로블록스 클라이언트 `RobloxPlayerBeta.exe`를 자동으로 찾습니다. PC 전체 인터넷이나 네트워크 어댑터를 끄지 않으며, 게임 실행 자체를 일시 정지하는 기능은 아닙니다.

## 다운로드 · 실행

**[Windows x64 실행 파일 다운로드](https://github.com/0naire/RobloxPause3s/raw/refs/heads/main/dist/RobloxPause3s.exe)** · [실행 파일 보기](dist/RobloxPause3s.exe)

1. 실행 파일을 내려받아 쓰기 가능한 폴더에 저장합니다. 별도 설치 과정은 없습니다.
2. `RobloxPause3s.exe`를 실행하고 관리자 권한 요청을 승인합니다.
3. Roblox 게임을 실행합니다. 프로그램에 **사용 준비 완료**가 표시되면 사용할 수 있습니다.
4. **F8** 또는 **3초간 연결 끊기** 버튼을 누릅니다. 약 3초 뒤 프로그램이 차단을 해제합니다.

다운로드한 실행 파일은 디지털 서명이 없는 개인 제작 프로그램입니다. 실행 전 공개된 소스와 [SHA-256](dist/SHA256SUMS.txt)을 확인할 수 있습니다.

## 단축키

| 기능 | 기본 키 |
| --- | --- |
| 3초간 연결 차단 | **F8** |
| 즉시 차단 해제 | **Ctrl + Alt + R** |
| 차단 키 변경 | 프로그램에서 **F6 ~ F12** 선택 |

단축키는 프로그램이 실행 중일 때 작동합니다. 다른 프로그램이 키를 이미 사용 중이면 안내 문구가 표시되므로 다른 키를 선택해 주세요. 복구 단축키가 충돌하면 **즉시 복구** 버튼을 사용할 수 있습니다.

## 주요 기능

- 실행 중인 Roblox의 경로 자동 감지: 업데이트로 설치 경로가 바뀌어도 다음 실행 시 다시 찾습니다.
- 약 3초간 차단한 뒤 자동 해제하며, 진행 중 중복 입력은 무시합니다.
- 남은 시간 표시와 수동 즉시 복구 버튼을 제공합니다.
- 일반 네트워크 어댑터 설정과 Windows 방화벽 프로필의 켜짐/꺼짐 값을 변경하지 않습니다.
- 별도 작업 프로세스가 타이머를 처리합니다. 작업 프로세스가 종료되면 Windows가 해당 동적 필터를 제거합니다.
- 설치 프로그램, 상주 서비스, 자동 시작 등록 없이 동작합니다.

## 작동 방식

Windows Filtering Platform(WFP)에 **동적 세션**을 열고, 감지한 실행 파일의 경로를 조건으로 차단 필터를 추가합니다. IPv4/IPv6의 연결 승인 및 수신 승인 계층을 사용합니다. 타이머가 끝나거나 즉시 복구 신호가 오면 세션을 닫아 필터를 제거합니다.

필터는 실행 파일 경로를 기준으로 적용됩니다. 동일한 파일 경로에서 여러 Roblox 프로세스가 실행 중이면 함께 영향을 받을 수 있습니다. 일반 사용 화면에서는 실행 중인 Roblox만 대상으로 감지합니다.

## 사용 환경과 한계

- **Windows 11 x64에서 확인했습니다.** Windows 10 x64는 API 호환 대상이지만 이 배포본에서는 별도로 시험하지 않았습니다.
- **.NET Framework 4.8 이상**, 관리자 권한, Windows Base Filtering Engine(BFE)이 필요합니다.
- 데스크톱 클라이언트 `RobloxPlayerBeta.exe`를 대상으로 합니다. macOS, 모바일, Xbox 및 이름이 다른 클라이언트는 지원하지 않습니다.
- **3초 뒤 해제되는 것은 로컬 차단입니다.** 서버가 연결을 종료한 경우에는 직접 재접속해야 하며, 세션 유지나 게임 내 동작은 보장하지 않습니다.
- 카운트다운은 화면 표시용입니다. Windows 스케줄링 등에 따라 실제 시간은 조금 달라질 수 있습니다.
- 다른 보안 프로그램이나 네트워크 필터와의 조합에서는 결과가 달라질 수 있습니다.

## 설정 · 오류 파일

| 파일 | 용도 |
| --- | --- |
| `hotkey.txt` | 선택한 차단 단축키. 실행 파일과 같은 폴더에 저장됩니다. |
| `error.log` | 오류 발생 시 진단 내용. 실행 파일과 같은 폴더에 저장됩니다. |

로그에는 로컬 실행 경로가 포함될 수 있으므로 공유 전 내용을 확인해 주세요. 위 파일은 저장소 업로드 대상에서 제외했습니다.

## 직접 빌드하기

64비트 .NET Framework C# 컴파일러가 있는 Windows에서 저장소 루트를 기준으로 실행합니다. NuGet 패키지나 외부 라이브러리는 사용하지 않습니다.

```powershell
powershell -NoProfile -File .\source\build.ps1
```

결과는 `dist\RobloxPause3s.exe`입니다. 실행 정책 때문에 스크립트가 차단되면 환경에 맞는 정책을 확인해 주세요. 빌드 자체에는 관리자 권한이 필요하지 않습니다.

## 검증

전용 로컬 테스트 실행 파일을 대상으로 자동 해제, 수동 복구, 작업 프로세스 강제 종료 시 필터 제거, TCP/UDP 및 IPv4/IPv6, 다른 앱의 연결 유지 여부를 검증합니다. 테스트는 실제 게임을 차단하지 않습니다.

```powershell
# 관리자 권한 PowerShell에서 실행
powershell -NoProfile -File .\tests\run.ps1
```

세부 결과와 시험 범위는 [검증 기록](docs/VERIFICATION.md)을 참고하세요.
